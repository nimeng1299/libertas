# Libertas

## 通用工具与合成材料

| 名称 | 用途 | 使用方式与限制 |
| --- | --- | --- |
| **18cm的木棍** | 可以用经验培养的无限耐久武器。基础攻击伤害随武器的经验等级增长，最低为 1。 | 手持时 **Shift + 右键**，将玩家的全部经验转入武器，玩家经验随之清零；创造模式每次增加 1000 点经验。不能通过附魔台或附魔书附魔。 |
| **深海回响** | 无限耐久的挖掘工具，镐类挖掘等级为 32，普通可破坏方块固定用 10 tick（0.5 秒）挖掘。 | 不会让基岩等不可破坏方块变得可挖掘；硬度为 0 的方块仍按原版瞬间破坏。 |
| **拼图** | 多数机器和辅助方块的通用升级合成材料，也可以作为手持装饰。 | 通常与对应模组的原始设备无序合成，例如「坩埚 + 拼图 → 高级坩埚」「魔力池 + 拼图 → 机械魔力池」。本身没有主动交互功能。 |
| **棉签** | 记录生物种类，为神奇的刷怪笼提供采样。 | **右键生物**记录或覆盖已有记录，**Shift + 右键空气**擦除记录。不能记录玩家、Boss 或没有注册实体 ID 的生物。 |

## 神秘时代（Thaumcraft）

| 名称 | 用途 | 使用方式与限制 |
| --- | --- | --- |
| **紫色心情** | 自动充能的法杖，可用于神秘时代的法杖交互、奥术合成和焦点等功能。 | 六种基础元素各可储存 1000 点 Vis；**手持时**每秒为每种元素独立随机补充 0～10 点。仅放在背包中不会自动充能。 |
| **碧空之泪** | 大幅稳定注魔祭坛，抑制注魔过程中的不稳定事故。 | 放在符文矩阵的有效扫描范围内：水平 ±12 格，矩阵下方 10 格至上方 5 格。会将祭坛的不稳定度压至 -10000 或更低；也是秘纹织契的结构部件。 |
| **要素罐** | 同时储存多种要素，供注魔祭坛及其他源质系统使用，适合大容量储存和搬运。 | 每种要素上限为 2,147,483,647。放置后仅从顶面连接源质管道，每 5 tick 吸取 1 点；手持罐子对源质容器**右键吸取全部要素**，**Shift + 右键尽量倒入**。拆下后保留已存要素。 |
| **要素熔炼舱** | 将物品按神秘时代的要素值 1:1 熔解，为高级坩埚和秘纹织契提供要素。 | 每秒尝试熔解 1 件输入物品，每种要素最多储存 64 点。任一要素放不下时不消耗物品；由多方块控制器直接取用，不通过源质管道输出。**拆除会清空已存要素**。 |
| **高级坩埚** | 自动执行神秘时代的坩埚合成配方。 | 催化剂放入输入总线，要素由结构内的要素熔炼舱提供，产物进入输出总线。固定 **1 tick** 完成，不设固定并行上限，实际产量受催化剂和要素数量限制。 |
| **秘纹织契** | 自动执行神秘时代的注魔合成配方。 | 核心物品与组件放入输入总线，要素由要素熔炼舱提供，产物进入输出总线。每轮 **1 次注魔，耗时 5 秒**；符文矩阵、奥术基座和注魔立柱需按结构提示手动摆放，并在矩阵正上方放置碧空之泪。 |

使用高级坩埚或秘纹织契时，可以先让要素熔炼舱熔解原料，再向输入总线提供合成物品。要素不足时，机器 GUI 会列出缺少的要素。

## 巫术（Witchery）

| 名称 | 用途 | 使用方式与限制 |
| --- | --- | --- |
| **灵泉** | 增强巫术祭坛的魔力容量和恢复速度。 | 放在祭坛任意一块的**正上方**：基础容量 +10，容量倍率 ×100，回魔倍率 ×100。可与原有祭坛文物效果共存，同一祭坛放多个灵泉不叠加。 |
| **大巫师烤炉** | 自动运行巫师烤炉的熔烧配方，批量获得主产物和烟气。 | 无需燃料；被烤物和空黏土罐放入输入总线。产烟气时每份消耗 1 个空黏土罐，主产物与烟气均为 100% 产出；每轮最多 **16 份，耗时 5 秒**。 |
| **巫师蒸馏塔** | 自动运行巫术蒸馏配方，制作各种蒸馏产物。 | 原料和配方要求数量的空黏土罐放入输入总线，产物进入输出总线。无需原版祭坛供能，每轮 **1 份，耗时 3 秒**。 |
| **大巫师炼药锅** | 自动运行巫师炼药锅（Witch's Cauldron）的仪式配方，例如各色粉笔、变异泰迪斯、无限水 / 燃料瓶等。 | 输入总线需要同时提供**配方原料和触发物**，产物 100% 进入输出总线。无需额外供水、热源或祭坛供能，每轮 **1 份，耗时 3 秒**。处理的是炼药锅仪式，不是 Kettle 水壶配方。 |

## 植物魔法（Botania）

| 名称 | 用途 | 消耗与特点 |
| --- | --- | --- |
| **风息花** | 不消耗燃料、不会枯萎的产能花，为魔力系统持续提供魔力。 | 每 tick 产生 **5000 点魔力**，内部缓冲 10000 点。需要连接魔力接收系统；接收端与内部缓冲满后停止积累，不会无限储存。 |
| **机械魔力池** | 用物品栏自动执行魔力池注入配方，不必把物品丢进池子。 | 按对应配方消耗魔力。升级槽放入**炼金催化器**或**炼造催化器**可追加相应配方，普通魔力池配方仍可使用。 |
| **机械符文祭坛** | 自动制作符文祭坛配方中的产物。 | 消耗配方魔力，并且每次额外消耗 **1 个活石**。与原版祭坛不同，**配料中的符文也会被消耗，不返还**。 |
| **微型精灵门** | 在单方块内自动执行精灵交易，获得梦之木、源质钢、精灵石英、龙石等产物。 | 每次交易固定消耗 **500 点魔力**，不需要搭建原版精灵门结构。 |
| **工业凝聚板** | 将泰拉钢生产压缩为单方块自动化，无需原版的青金石 / 活石平台。 | 每次消耗 **1 个魔力钢锭 + 1 个魔力珍珠 + 1 个魔力钻石 + 500000 点魔力**，产出 1 个泰拉钢锭。当前只处理这套泰拉钢配方。 |
| **机械花药台** | 自动执行花药台的花瓣配方，生产各类花。 | 每次消耗配料、**1 个小麦种子和 500 点魔力**，无需加水。种子槽只接受小麦种子。 |
| **机械白雏菊** | 自动执行白雏菊的物品转换配方，例如石头 → 活石、原木 → 活木。 | 每次转换消耗 **100 点魔力**。无需把方块围在花旁边；没有可用物品形态的配方（例如水 → 雪）会跳过。 |
| **机械植物酿造台** | 自动执行植物酿造台的酿造配方。 | 需要配料和 **1 个植物魔法酿造容器**（实现 `IBrewContainer` 的瓶子）。产物容器类型与输入容器对应，魔力消耗由配方和容器决定。 |

### 机械设备的通用使用方式

- 每台设备最多储存 **1000000 点魔力**，可接受魔力束充能。除机械魔力池自身外，其余设备还能自动从六个相邻方向的魔力池抽取魔力，每个相邻池最多 1000 点 / tick。
- 将原料和专用槽物品放入后，设备自动匹配配方；魔力不足或产物放不下时，不消耗本次配料。

## 血魔法（Blood Magic）

| 名称 | 用途 | 使用方式与限制 |
| --- | --- | --- |
| **赤泉** | 自动为血之祭坛补充生命精华（LP）。 | 紧贴放在血之祭坛的**正下方**，每 **5 tick 注入 1000 LP**，受祭坛当前容量上限限制。 |
| **猩红祭仪** | 自动向血之祭坛投放配方原料，并在完成后取回产物。 | 血之祭坛必须紧贴设备的**正后方**。配方仍由真实祭坛完成，因此需要满足祭坛等级和 LP 要求；不处理没有物品产物的血球充能配方。 |

可以把赤泉放在祭坛下方、猩红祭仪放在祭坛前方，再为猩红祭仪接入自动投料和产物回收，实现祭坛合成自动化。GUI 的「重置」只取消当前配方跟踪，**不会自动取回祭坛内的物品**。

## 资源生产设备

| 名称 | 用途 | 使用方式与限制 |
| --- | --- | --- |
| **迷你矿机** | 无输入持续产出基础矿石。 | 用圆石和圆石墙搭建结构并接上输出总线；每 **3 秒随机产出 1 个铁、铜、锡或煤矿石**，无需电力、燃料和维护。 |
| **神奇的刷怪笼** | 根据棉签记录的生物种类，自动生产该生物的常规掉落物。 | 放入已采样的棉签，每 **10 秒**模拟一次无抢夺的玩家击杀，掉落物进入 16 个输出槽。不实际生成生物，不提供经验或完整死亡事件奖励；输出放不下时本轮不产出。**收到红石信号时暂停**。 |
